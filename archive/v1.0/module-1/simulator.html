What this teaches

  • The arrow back is the difference. The same stuck sensor is harmless in a shadow and expensive in a twin.
  • A stuck value looks like a calm reading. Neither the dashboard nor the twin notices unless something checks.
  • Latency adds up hop by hop, and a twin acting on old readings overshoots.
  • Validation is a design decision: how long unchanged is "stuck", how fast is "impossible", how old is "stale".

This is a simplified browser model for building intuition, not the real build: there is no real broker, database or dashboard, each reading stands for one minute of room time, and the room's physics is simplified.
