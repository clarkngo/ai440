GitHub

First needed: HOS 1Free — no credit card

What it's for: your own repo for each HOS and Application Challenge, created from the invite link in each module, and the Codespace you open from it.

  1. Go to github.com and click Sign up.
  2. Enter an email, create a password and pick a username. Use something professional: this account is worth keeping for internships and job applications.
  3. Verify your email when GitHub sends the confirmation.
  4. Recommended: apply for the free GitHub Student Developer Pack. It adds GitHub Copilot and more Codespaces hours.
Already have a GitHub account? Use that one. One consistent profile is more useful to you later than several scattered ones.

You'll know it worked when…

  • You can create a Codespace on any of your repos, and Copilot's chat answers inside it.
🔑

Google AI Studio: Gemini API key

First needed: HOS 4 (Week 7)Free — no credit card

What it's for: the key that lets your HOS 4 agent, built with Google's Agent Development Kit, call Gemini. You get it once and reuse it.

  1. Go to aistudio.google.com/apikey and sign in with a personal Google account (a Gmail address). School and work accounts may be refused.
  2. Click Create API key.
  3. Copy the long string it gives you. It starts with something like AIza.
  4. In your HOS 4 Codespace, copy .env.example to .env and paste the key after GOOGLE_API_KEY=.
Treat this like a password. Never paste it into a file you commit, a chat, an AI assistant's prompt, or a screenshot. The free tier needs no billing account; if a call fails with a rate-limit error (429), wait a minute and try again. The starter sets the model to gemini-3.8-flash, which works with new keys; older model names may not.

You'll know it worked when…

  • The HOS 4 agent answers in adk web --allow_origins "*". A missing or wrong key shows an error on the first message.

Putting it all together

Only the HOS 4 repo (and your Term Project, if it uses an agent) needs a key. Its .env, copied from .env.example, holds:

GOOGLE_GENAI_USE_VERTEXAI=FALSE
GOOGLE_API_KEY=AIzaSyD-your-real-key-goes-right-here
MODEL=gemini-3.8-flash

This file is excluded from Git by each repo's .gitignore. It stays in your Codespace and is never committed.
